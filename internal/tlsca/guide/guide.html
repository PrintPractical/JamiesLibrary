Check it is really this library

Anyone on your network could swap the file you download for another one. So each set of steps above tells you to compare the SHA-256 fingerprint your device shows for the certificate with the one on the library's server console, or on the Settings page when an administrator is signed in. Compare the first 8 and the last 8 characters. Capitals, spaces and colons don't matter. If they differ, don't trust it.

This page's own copy is for reference only, and is not the check: this page came over a connection that isn't encrypted, so it could have been changed on the way.

What your device will trust

Only this library installation, and local names and private network addresses (such as 192.168.x.x or library.local) signed by its key. It cannot vouch for any public website, such as your bank, even if its key were stolen.
